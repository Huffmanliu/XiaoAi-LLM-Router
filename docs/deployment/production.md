# 单域名生产部署

网页平台和旧 CLI 都会监听音箱，同一设备只能运行其中一个。双域名绑定尚未实现；
当前版本仍在平台域名内完成小米绑定。

## 目录和服务

- `/opt/xiaoai-platform/releases/COMMIT`：经过验证的 Git 提交及独立 Python 3.11/3.12 环境。
- `/opt/xiaoai-platform/current`：指向当前提交目录的符号链接。
- `/etc/xiaoai-platform/platform.env`：生产环境配置，参照 `platform.env.example`，由 root 管理。
- `/etc/xiaoai-platform/platform.key`：生产独立加密密钥，0600，不与数据库备份打包。
- `/etc/xiaoai-platform/mail.json`：私有 SMTP 配置，0600，参照 `mail.example.json`。
- `/var/lib/xiaoai-platform`：配置与用量数据库、独立历史数据库和实例锁。
- `xiaoai-platform.service`：参照 `xiaoai-platform.service.example`，只监听服务器回环地址。

生产需设置 `PLATFORM_DEPLOYMENT=production`、固定 HTTPS 来源、安全 Cookie、
可信本机代理和 `PLATFORM_ENVIRONMENT=生产环境`。通过 `PLATFORM_ROUTER_CONFIG`
引用生产路由配置；模型 Key 通过原私有环境文件注入，不放进 Git。
生产排除本机开发音箱，本机排除生产音箱。不能同时启动两份监听相同设备的程序。

## 首次迁移

先运行测试、检查发布文件中无真实凭据，并把确定的提交推送到自己的 GitHub 仓库。
按提交构建独立发布目录，不覆盖旧 CLI 的代码、虚拟环境或私有配置。
保留旧服务和启用状态，用配置与用量维护工具备份；聊天记录不纳入常规备份。

新建生产数据库和生产主密钥，不复制本机测试数据库、测试用户、聊天历史或登录会话。
确需保留管理员登录时，只迁移已确认归属的管理员密码哈希与安全邮箱，邮箱仍须验证。
既有生产小米绑定和已启用设备可在停旧服务后迁入新数据库，以保持设备选择；
其余发现设备不自动勾选。旧 JSONL 用量通过 `platform_app.admin import-usage` 幂等导入。

停旧服务前确认当前回答与播报已结束，正常停止并确认进程退出，再启动新服务。
验证新实例存活、HTTPS、未登录接口拒绝访问和监听设备分工；不得用真实发声或付费模型
调用作为自动部署探针。保留回退路径，失败先停止新平台，确认退出后再恢复旧服务。

## 网页入口与回退

已有 Nginx 等代理时，只增加本项目的独立站点，先校验配置再平滑重载。
不得替换默认站点、重启其他应用或修改其数据库。端口被占用时不要另起 Caddy 抢占。
没有正式域名和证书时，可先安装发布目录；网页使用 SSH 转发的回环入口测试，
不要把接收密码的页面通过公网 HTTP 开放。临时入口也必须符合平台的来源和 Cookie 配置。可用仅监听回环的独立Nginx TLS站点，再经SSH转发；临时自签名证书应校验公钥，在独立测试浏览器内固定信任，不全局关闭证书验证或修改系统信任。临时入口不面向公众用户。

更新时保留原 `current` 目标。检查没有占位请求或提交中的播报后正常停平台，切换
`current` 并启动；异常则停止新实例、恢复原链接和配置，再启动原版本。
发生数据库迁移后须评估旧版本兼容性，必要时恢复停服前的配置与用量备份；
不能把升级后的数据库直接交给不兼容的旧版本。

## 跨服务器迁移

接入资料保存在私有交接文件，不把服务器地址、密钥或数据库加入仓库。与同机其他项目分开使用本项目的用户、目录、服务和回环端口；只增加独立代理配置并平滑加载，不改其他项目的服务或数据库。

先在目标安装与本机验证一致的锁定依赖，运行完整合成测试、依赖检查和源码校验。准备私有配置及 HTTPS，但不启动音箱监听。生产加密主密钥单独通过 SSH 传输，权限保持0600，不能放入配置与用量备份；没有原密钥就不能解开旧账号凭据和模型配置。

切换前确认旧网页服务没有占位请求或提交中的播报、旧 CLI 未运行，正常停旧服务并核对实例锁释放。使用已有维护工具创建不含会话、验证码、邮件队列及聊天历史的配置与用量备份，再迁移元数据；加密历史库按独立文件直接迁往目标，不混入备份包，不落到开发机。核对账号、归属、设备启用选择、设置、模型配置、订单/用量及历史文件一致，并离线验证解密后才启动目标。迁移不会复制本机账号或沙箱配置，也不打开收费。

核对新服务 HTTPS、帮助页面、静态文件、保护接口和数据库迁移；确认同机其他项目正常，再关闭旧服务自启、开启新服务自启，并更新本机私有入口。迁移不保留网页登录会话，需要重新登录。

回退必须先确认目标服务停止且实例锁释放，再恢复旧实例。目标启动后如产生新请求、历史或用户写入，须先保全并核对新数据，不能直接恢复旧快照。旧代码与数据保留只用于回退，不能再次并行启动。
